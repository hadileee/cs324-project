# CS324 Project

## Description
A React-based web application project for CS324 coursework. This project uses modern web development practices and follows a component-based architecture.

## Technologies Used
- React 19.2.0 - Frontend framework
- React Router - For client-side routing
- Axios - For API requests
- Create React App - Development environment
np
